## 2. Table Definitions

### 2.1 `users`
Stores all registered accounts (Caregivers, Care Seekers, and Admins).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `id` | `BIGINT` | `NOT NULL` | `IDENTITY` | Primary Key (`GENERATED BY DEFAULT AS IDENTITY`) |
| `email` | `VARCHAR(255)` | `NOT NULL` | — | `UNIQUE` (stored trimmed and lower-cased by `User.java`) |
| `password_hash` | `VARCHAR(255)` | `NULL` | — | BCrypt hash; made nullable in `V2` for Google-only sign-ins |
| `google_sub` | `VARCHAR(64)` | `NULL` | — | `UNIQUE`; Google OIDC Subject identifier (`V2`) |
| `full_name` | `VARCHAR(150)` | `NOT NULL` | — | Display name |
| `phone` | `VARCHAR(30)` | `NULL` | — | Contact phone number |
| `role` | `VARCHAR(20)` | `NOT NULL` | — | `CHECK (role IN ('CAREGIVER', 'CARE_SEEKER'))` |
| `is_admin` | `BOOLEAN` | `NOT NULL` | `FALSE` | Admin privilege flag (`V8`), orthogonal to `role` |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Account creation timestamp |

**Indexes**:
- Primary Key on `(id)`
- Unique constraint on `(email)`
- Unique constraint on `(google_sub)` (`idx_users_google_sub`)

### 2.2 `caregiver_profiles`
Stores professional profile details and listing eligibility for users with `role = 'CAREGIVER'`.

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `user_id` | `BIGINT` | `NOT NULL` | — | Primary Key; Foreign Key -> `users(id) ON DELETE CASCADE` |
| `age` | `INT` | `NULL` | — | `CHECK (age IS NULL OR (age BETWEEN 18 AND 100))` |
| `experience_years` | `INT` | `NULL` | — | `CHECK (experience_years IS NULL OR (experience_years BETWEEN 0 AND 60))` |
| `job_type` | `VARCHAR(30)` | `NULL` | — | `CARETAKER`, `NURSING`, or `PHYSIOTHERAPIST` (`V4`) |
| `qualification` | `VARCHAR(255)` | `NULL` | — | Professional qualifications & bio |
| `address` | `VARCHAR(300)` | `NULL` | — | Residential area / base address (`V11`, admin-visible only) |
| `photo_file` | `VARCHAR(80)` | `NULL` | — | UUID filename in `uploads/photos` |
| `available` | `BOOLEAN` | `NOT NULL` | `TRUE` | Caregiver self-toggled availability (`V6`) |
| `listed` | `BOOLEAN` | `NOT NULL` | `FALSE` | Public directory eligibility (`V10` as `verified`, renamed to `listed` in `V11`) |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Last update timestamp |

### 2.3 `caregiver_rates`
Stores rate tiers per caregiver (1-to-many collection table owned by `caregiver_profiles`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `user_id` | `BIGINT` | `NOT NULL` | — | PK part 1; Foreign Key -> `caregiver_profiles(user_id) ON DELETE CASCADE` |
| `rate_type` | `VARCHAR(20)` | `NOT NULL` | — | PK part 2; `HOURLY`, `SESSION`, `DAILY`, or `FULL_DAY_NIGHT` |
| `amount` | `NUMERIC(10, 2)` | `NOT NULL` | — | `CHECK (amount > 0)` |

---

### 2.4 `caregiver_documents`
Stores metadata and review status for identity and qualification documents uploaded by caregivers (`V10`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `id` | `BIGINT` | `NOT NULL` | `IDENTITY` | Primary Key |
| `user_id` | `BIGINT` | `NOT NULL` | — | Foreign Key -> `caregiver_profiles(user_id) ON DELETE CASCADE` |
| `doc_type` | `VARCHAR(30)` | `NOT NULL` | — | `NIC`, `GS_LETTER`, `NURSING_CERTIFICATE`, or `DEGREE_CERTIFICATE` |
| `file_name` | `VARCHAR(80)` | `NOT NULL` | — | UUID filename in `uploads/documents` |
| `status` | `VARCHAR(10)` | `NOT NULL` | — | `PENDING`, `APPROVED`, or `REJECTED` |
| `revision` | `INT` | `NOT NULL` | `1` | Incremented on re-upload |
| `reject_reason` | `VARCHAR(300)` | `NULL` | — | Reason provided by admin when `status = 'REJECTED'` |
| `reviewed_by` | `BIGINT` | `NULL` | — | Foreign Key -> `users(id) ON DELETE SET NULL` |
| `reviewed_at` | `TIMESTAMPTZ` | `NULL` | — | Timestamp of admin review |
| `uploaded_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Timestamp of latest upload |

**Constraints & Indexes**:
- `CONSTRAINT uq_caregiver_document UNIQUE (user_id, doc_type)`
- `INDEX idx_caregiver_documents_status ON caregiver_documents (status, uploaded_at)`

### 2.5 `document_requirements`
Stores the admin-configurable matrix of which `DocumentType` values are mandatory for each `JobType` (`V11`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `job_type` | `VARCHAR(30)` | `NOT NULL` | — | PK part 1 (`CARETAKER`, `NURSING`, `PHYSIOTHERAPIST`) |
| `doc_type` | `VARCHAR(30)` | `NOT NULL` | — | PK part 2 (`NIC`, `GS_LETTER`, `NURSING_CERTIFICATE`, `DEGREE_CERTIFICATE`) |
| `required` | `BOOLEAN` | `NOT NULL` | `FALSE` | Whether this document must be `APPROVED` for `listed = true` |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Last modification timestamp |
| `updated_by` | `BIGINT` | `NULL` | — | Foreign Key -> `users(id) ON DELETE SET NULL` |

### 2.6 `reviews`
Stores care seeker ratings (1–5 stars) and comments for caregivers (`V7`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `id` | `BIGINT` | `NOT NULL` | `IDENTITY` | Primary Key |
| `caregiver_id` | `BIGINT` | `NOT NULL` | — | Foreign Key -> `caregiver_profiles(user_id) ON DELETE CASCADE` |
| `reviewer_id` | `BIGINT` | `NOT NULL` | — | Foreign Key -> `users(id) ON DELETE CASCADE` |
| `rating` | `INT` | `NOT NULL` | — | `CHECK (rating BETWEEN 1 AND 5)` |
| `comment` | `VARCHAR(1000)` | `NULL` | — | Optional review text |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | First submission timestamp |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Latest update timestamp |

**Constraints & Indexes**:
- `CONSTRAINT uq_review_per_pair UNIQUE (caregiver_id, reviewer_id)`
- `INDEX idx_reviews_caregiver ON reviews (caregiver_id, updated_at DESC)`

### 2.7 `bookings`
Stores care seeker booking requests and their coordination status (`V8`, `V11`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `id` | `BIGINT` | `NOT NULL` | `IDENTITY` | Primary Key |
| `seeker_id` | `BIGINT` | `NOT NULL` | — | Foreign Key -> `users(id) ON DELETE CASCADE` |
| `caregiver_id` | `BIGINT` | `NOT NULL` | — | Foreign Key -> `caregiver_profiles(user_id) ON DELETE CASCADE` |
| `status` | `VARCHAR(20)` | `NOT NULL` | — | `REQUESTED`, `CONFIRMED`, `COMPLETED`, or `CANCELLED` |
| `seeker_phone` | `VARCHAR(30)` | `NOT NULL` | — | Callback phone number provided by seeker |
| `address` | `VARCHAR(300)` | `NULL` | — | Care delivery address (`V11`, validated `@NotBlank` on new requests) |
| `rate_type` | `VARCHAR(20)` | `NULL` | — | Selected `RateType` |
| `quoted_amount` | `NUMERIC(10, 2)` | `NULL` | — | Historical snapshot of caregiver's rate at booking creation |
| `note` | `VARCHAR(500)` | `NULL` | — | Optional care instructions |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Booking creation timestamp |
| `updated_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Latest status transition timestamp |

**Indexes**:
- `INDEX idx_bookings_seeker ON bookings (seeker_id, created_at DESC)`
- `INDEX idx_bookings_status ON bookings (status, created_at DESC)`

### 2.8 `notifications`
Transactional outbox table for asynchronous Email and WhatsApp alert delivery (`V8`, `V9`).

| Column | SQL Type | Nullable | Default | Constraints & Notes |
|---|---|---|---|---|
| `id` | `BIGINT` | `NOT NULL` | `IDENTITY` | Primary Key |
| `booking_id` | `BIGINT` | `NULL` | — | Foreign Key -> `bookings(id) ON DELETE CASCADE` |
| `channel` | `VARCHAR(20)` | `NOT NULL` | — | `EMAIL` or `WHATSAPP` |
| `recipient` | `VARCHAR(500)` | `NOT NULL` | — | Comma-separated emails or E.164 phone number (widened in `V9`) |
| `template` | `VARCHAR(80)` | `NOT NULL` | — | Email subject or WhatsApp template name (`new_booking_details`) |
| `language` | `VARCHAR(10)` | `NOT NULL` | — | `"en"` |
| `params` | `VARCHAR(4000)` | `NULL` | — | Email body or JSON array of WhatsApp template variables (widened in `V9`) |
| `status` | `VARCHAR(12)` | `NOT NULL` | — | `PENDING`, `SENT`, or `FAILED` |
| `attempts` | `INT` | `NOT NULL` | `0` | Delivery attempt counter (max 5) |
| `last_error` | `VARCHAR(500)` | `NULL` | — | Truncated error message from latest failed attempt |
| `next_attempt_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Next scheduled poll timestamp |
| `created_at` | `TIMESTAMPTZ` | `NOT NULL` | `now()` | Enqueue timestamp |
| `sent_at` | `TIMESTAMPTZ` | `NULL` | — | Successful delivery timestamp |

**Indexes**:
- `INDEX idx_notifications_due ON notifications (status, next_attempt_at)`
- `INDEX idx_notifications_booking ON notifications (booking_id)`
