### 2.5 Architectural Boundaries & Unimplemented Features
1. **Single-Instance Outbox Polling & Local Disk Storage**:
   - [`NotificationRepository.findDueIds`](file:///home/sivaram/Github/homecare-connect/backend/src/main/java/com/homecare/notification/NotificationRepository.java#L14-L16) selects `PENDING` notifications without `FOR UPDATE SKIP LOCKED` or distributed locking, and [`PhotoStorage`](file:///home/sivaram/Github/homecare-connect/backend/src/main/java/com/homecare/profile/PhotoStorage.java) / [`DocumentStorage`](file:///home/sivaram/Github/homecare-connect/backend/src/main/java/com/homecare/verification/DocumentStorage.java) write to local disk (`./uploads`). Running multiple backend replicas requires sticky/shared storage and row-level locking on outbox polling.

   - [`AdminUserService.delete`](file:///home/sivaram/Github/homecare-connect/backend/src/main/java/com/homecare/admin/AdminUserService.java#L85-L104) performs a hard `ON DELETE CASCADE` delete; there is no account suspension/deactivation state that preserves historical bookings/reviews.
3. **Unbuilt Notification Extensions**:
   - As noted in [`README.md`](file:///home/sivaram/Github/homecare-connect/README.md#L139), WhatsApp delivery receipt/reply webhooks and admin alerts when a seeker cancels a booking are not implemented.
4. **Frontend Test Suite & Backend CI/CD**:
   - Backend has 11 comprehensive integration/unit test classes; `frontend/package.json` has no test runner configured, and `.github/workflows/` only automates frontend deployment.
